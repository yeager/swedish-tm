# Swedish TP review, 2026-09-20

This is an ongoing complete language review of Translation Project's 146 Swedish domains. 107,269 of 127,367 active entries have been individually read. The review is not complete.

This update adds 47 unambiguous, verified English–Swedish pairs from the expanded review to `sv-tp.po` and regenerates `sv-tp.tmx` from exactly the same PO data. The current audit contains 476 imported pairs. 70 context-free pairs with competing reviewed targets are deliberately excluded: Translation Memory lacks the gettext domain and message context needed to choose safely.

Every imported pair has an exact English source and prior Swedish target match. The full export validator checks GNU gettext syntax, XML structure, PO/TMX pair agreement and regenerated statistics across all ecosystem files.

[Change audit](reviews/tp-2026-09-20.json) records every applied pair. The [Translation Project Swedish team](https://translationproject.org/team/sv.html) and [Swedish FOSS terminology](https://github.com/yeager/swedish-foss-terminology) provide review context.
